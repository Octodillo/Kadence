Kadence 0.1.0 is the first release of Kadence, a digital audio workstation
for KDE Plasma. It is an early release: it can record, arrange, edit, mix and
export a song, but expect rough edges, and keep backups of projects you care
about.

## What you can do

- **Record** audio and MIDI onto armed tracks, with a count-in and a
  metronome. Each track picks its own audio input and MIDI input.
- **Arrange** clips on a timeline: move, trim, split and duplicate them, set fades and clip gain, loop a range, and import audio
  files (WAV, FLAC, MP3, Ogg Vorbis and more).
- **Edit MIDI** in the piano roll: draw, move and resize notes, quantize,
  humanize, transpose, and fix overlaps or make notes legato.
- **Play instruments**: instrument tracks start with Kadence's synth, and
  you can swap it for the sampler or any CLAP, VST3 or LV2 instrument.
- **Mix** in the Mix page: volume, pan, mute, solo, effect inserts, sends
  (before or after the fader), buses and track output routing, with
  resizable strips and the metronome's own strip.
- **Use effects and plugins**: built-in EQ, compressor, delay, reverb and
  utility, plus CLAP, VST3 and LV2 plugins, each running in its own process
  so a crashing plugin can't take the song down; reload it from the device
  panel. Edit any device's parameters in the device panel, or open a
  plugin's own window from it.
- **Automate** volume, pan and device parameters with automation lanes in
  the arrange view, by drawing points, or record volume, pan and send moves
  while playing.
- **Set tempo and time signature**, with tap tempo.
- **Export** the song, a loop or a range of bars to WAV or FLAC.
- **Keep your work safe**: projects are folders that hold their audio,
  saves keep the last ten versions, a recovery copy is kept while you work,
  and missing audio files can be found and relinked.

Kadence talks to PipeWire (or JACK) and follows your Plasma theme, colors
and scale factor, light or dark.

## Install

| | |
|---|---|
| Any distribution | `kadence-0.1.0-x86_64.flatpak`: `flatpak install --user kadence-0.1.0-x86_64.flatpak` |
| Arch Linux, SteamOS (distrobox), Manjaro | `kadence-0.1.0-1-x86_64.pkg.tar.zst`: `sudo pacman -U kadence-0.1.0-1-x86_64.pkg.tar.zst` |
| Fedora | `kadence-0.1.0-1.fc*.x86_64.rpm`: `sudo dnf install ./kadence-0.1.0-1.fc*.x86_64.rpm` |
| From source | `kadence-0.1.0.tar.gz` has every Rust crate vendored, so it builds offline. See `packaging/README.md`. |

`SHA256SUMS` lists the checksums of every file. The Arch `PKGBUILD` is
attached too, for building the package yourself.

The Arch and Fedora packages are built against the current Arch and
Fedora releases. Built from source, Kadence needs Qt 6.8 and KDE Frameworks
6.13 or newer (Debian 13 and newer); use the Flatpak anywhere else. Flatpak
users who want plugins should install them from Flathub as
`org.freedesktop.LinuxAudio.Plugins.*` extensions, or put them in
`~/.clap`, `~/.vst3` or `~/.lv2`.

New to Kadence? Read the [user guide](https://github.com/Octodillo/Kadence/blob/v0.1.0/docs/user-guide.md).

Fedora packages on X11, Wayland and at 100% to 200% scale, the Flatpak
offscreen in its sandbox. Kadence was also tested on a Steam Deck (Arch

## Known issues

- Loading a plugin blocks the window for a moment
  ([#111](https://github.com/Octodillo/Kadence/issues/111)), and a plugin
  that failed to load needs the project reopened to try again
  ([#118](https://github.com/Octodillo/Kadence/issues/118)).
- Stopping an export can't interrupt a plugin that is still loading
  ([#116](https://github.com/Octodillo/Kadence/issues/116)).
- Two Kadence windows running at once share a JACK client name and can
  confuse each other's connections
  ([#107](https://github.com/Octodillo/Kadence/issues/107)).
- Overlapping audio clips don't crossfade automatically
  ([#102](https://github.com/Octodillo/Kadence/issues/102)).
- On a touch screen, the Arrange page pans with one finger on the track
  headers and empty lanes and opens menus with a long press, but a drag on
  a clip moves it. The piano roll is made for a mouse or touchpad: a
  one-finger drag there edits notes, and its menus need a right click.
- In the Flatpak under a Wayland session, plugins' own windows can't open,
  because they need X11; their parameters are all in the device panel
  ([#144](https://github.com/Octodillo/Kadence/issues/144)).
- Some VST3 plugins don't silence held notes when playback stops
  ([#72](https://github.com/Octodillo/Kadence/issues/72)).

Please report problems at https://github.com/Octodillo/Kadence/issues.
